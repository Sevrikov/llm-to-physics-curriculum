# 🧠 Від токену до фізики
### Навчальна програма ML-інжинерії нового покоління

> Бойова система рівнів для ML-інженерів стартапу — від першого API-виклику до моделей що розуміють фізику реального світу.

---

## Концепція

Програма побудована за **ММА-підходом**: спочатку бій, потім техніка, потім теорія.

```
БІЙ (запустив — щось зламалось або програв)
  → ТЕХНІК (конкретний прийом що вирішує проблему)
  → РОЗУМІННЯ (теорія пояснює чому прийом працює)
  → РЕВАНШ (складніший)
```

Прогрес вимірюється через benchmark score, не через тест знань. Кожен пояс закінчується «турнірним матчем» проти стандартного суперника.

## Система поясів

| Пояс | Рівень | Тижні | Ціль |
|------|--------|-------|------|
| ⬜ Білий | Учень API | 1–4 | Prompt-система, score ≥ 7.0/10 |
| 🟡 Жовтий | Майстер даних | 5–10 | Датасет 2000+, якість ≥ 8.0/10 |
| 🟠 Помаранчевий | Файн-тюнер | 11–18 | Win rate ≥ 60% vs GPT-4o |
| 🟢 Зелений | Інженер систем | 19–26 | Продакшн + авто-ретренінг |
| 🔵 Синій | Мультимодальний | 27–34 | VLM + перший embodied агент |
| 🟤 Коричневий | Архітект світів | 35–44 | World Model, передбачення фізики |
| ⬛ Чорний | Дослідник меж | 45–56+ | Нейроморфне залізо, оригінальний внесок |

**Мінімум до робочого AI-продукту:** Зелений пояс = 26 тижнів × 40 год/тиждень.

## Вектор розвитку

Поточні LLM — **асоціативні** (знають *що* відбувається з тексту).  
Ціль програми — підготовка до **каузального моделювання**: модель що симулює наслідки дій у фізичному світі.

```
TEXT LLM:     "кинутий м'яч летить по параболі"   ← знання
WORLD MODEL:  state_t + action → state_{t+1}       ← симуляція
```

Рівні 5–7 охоплюють: мультимодальність, World Models (DreamerV3), VLA-моделі (Lerobot, OpenVLA), нейроморфні обчислення (SpikingJelly, IBM AIHWKIT).

## Ключові технічні рішення

- **MemTorch** — abandoned з 2021, не сумісний з PyTorch 2.0+. Замінено на **IBM AIHWKIT**
- **Pi0** (Physical Intelligence) — закрита модель. Замінено на **Lerobot** (HuggingFace)
- **Apache Airflow** → **Prefect** для MVP; Airflow як опція масштабу
- **Genesis** — experimental, мінімальна документація; з попередженням
- **Lerobot** — найкращий вхід в embodied AI: `pip install lerobot`, stable 2025
