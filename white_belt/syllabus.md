# ⬜ Білий пояс — Syllabus
## «Учень API» — Онлайн-курс без ментора

**Загальна тривалість:** 4 тижні / 160 годин  
**Формат:** Самостійне навчання. Кожен урок — самодостатній: теорія → практика → самоперевірка.  
**Ціль:** Prompt-система для своєї ніші, LLM-judge score >= 7.0/10

---

## Як проходити курс

```
1. Читаєш «Теорію» уроку (5–15 хв)
2. Запускаєш скрипт, бачиш результат
3. Виконуєш «Завдання» (заповнюєш файли вручну)
4. Відповідаєш на «Питання самоперевірки»
5. Якщо щось зламалось → розділ «Якщо не працює»
6. Переходиш до наступного уроку
```

> ⚠️ **Важливо:** Не переходь до наступного уроку поки не виконав завдання поточного.  
> Завдання — не опціональні. Без них атестацію не пройдеш.

## ⛔ 7 типових пасток початківця

Gemini Deep Research і практика показують: майже всі новачки наступають на одні й ті самі граблі. Прочитай **до** початку курсу — зекономиш тижні.

**1. Вимагати 100% точності від ймовірнісної системи**  
LLM — не база даних. Вона не "знає" відповідь — вона генерує правдоподібне продовження. Проектуй систему з урахуванням похибки: confidence levels, fallback, human-in-the-loop.

**2. Давати агентам безмежну автономію**  
"Зроби все сам" → агент галюцинує по дорозі і ти не знаєш де. Починай з маленьких кроків з явними checkpoint'ами.

**3. Context stuffing — звалювати все в контекст**  
Більше токенів ≠ краща відповідь. Модель "забуває" початок при великому контексті. Вибирай що важливо, а не закидай все підряд.

**4. Передчасна мультиагентна складність**  
Один добре налаштований промпт вирішує 80% задач. Мультиагентна система — для Yellow Belt+.

**5. RAG як чорний ящик**  
"Підключимо базу знань і все запрацює" — ні. Якість retrieval визначає якість відповіді. RAG — окремий модуль з окремими тестами. (Yellow Belt тема)

**6. Перевантаження одного запиту**  
"Проаналізуй → порівняй → підсумуй → дай рекомендацію → склади звіт" в одному промпті. Краще: кілька focused запитів з проміжними результатами.

**7. Сліпе захоплення фреймворками**  
LangChain, LlamaIndex — корисні інструменти. Але розуміти що відбувається під капотом (цей курс) важливіше ніж знати API фреймворку.

## FAQ для самостійного навчання

**Q: Можна пропустити урок?**  
A: Можна пропустити Урок 07 (Cost Router) — він preview Жовтого поясу. Решта обов'язкові.

**Q: Скільки часу на урок?**  
A: Від 4 до 32 годин. Найдовший — Урок 08 (збірка системи). Не поспішай.

**Q: Що якщо моя ніша не юридична?**  
A: Заміни `NICHE`, `QUESTIONS`, `SYSTEM` на своє. Код однаковий для будь-якої ніші.

**Q: Що якщо немає GPU?**  
A: Ollama працює на CPU. Повільніше але достатньо для навчання. На CPU qwen2.5:7b = ~30 сек/відповідь.

**Q: Що якщо LLM-judge оцінює нижче 7.0?**  
A: Дивись розділ "Якщо score < 7.0" в Уроці 10 — є алгоритм виправлення.
