## 📖 Теорія (10 хвилин)

### Що таке LLM і навіщо нам API?

LLM (Large Language Model) — модель що передбачає наступний токен за попередніми. Вона не "думає" і не "розуміє" — вона статистично продовжує текст.

Є два способи використовувати LLM:
1. **Через API** (OpenAI, Anthropic) — платно, модель на чужих серверах
2. **Локально через Ollama** — безкоштовно, модель на твоєму комп'ютері

На цьому курсі ти будеш використовувати обидва. Ollama — для більшості розробки (безкоштовно), OpenAI API — для оцінки і складних задач.

### Чому важливо вибрати нішу ЗАРАЗ?

Без конкретної ніші ти будеш вчитись на абстрактних прикладах і не побачиш реального gap між "просто GPT-4o" і "GPT-4o з твоїм промптом". Ніша = мотивація + вимірювана ціль.

### Крок 2: Ollama

```bash
# Windows: завантажити з https://ollama.ai і встановити
# Або через winget:
winget install Ollama.Ollama

# Після встановлення — відкрити новий термінал і завантажити моделі
ollama pull qwen2.5:7b       # ~4GB, 15-30 хв залежно від інтернету
ollama pull qwen2.5:1.5b     # ~1GB, класифікатор

# Перевірка що все завантажилось
ollama list
# Має показати qwen2.5:7b і qwen2.5:1.5b
```

**Що відбувається під капотом — квантизація:**

Чому `qwen2.5:7b` займає 4GB, а не 14GB? Тому що Ollama завантажує квантизовану версію:

```bash
# Перевір скільки VRAM/RAM використовує запущена модель
ollama ps
# NAME                  ID        SIZE    PROCESSOR   UNTIL
# qwen2.5:7b:latest     abc123    4.7 GB  100% GPU    4 minutes from now
```

**GGUF** — формат квантизованих моделей. `Q4_K_M` означає 4 біти на параметр замість 16 (fp16). Результат: модель у ~3.5x менша і швидша, якість незначно нижча. Для нашого курсу — ідеально: повна потужність за ціну диску і RAM.

### Крок 4: OpenAI API ключ

1. Зайди на **platform.openai.com**
2. Верхнє меню → "API keys" → "Create new secret key"
3. Скопіюй ключ (він показується тільки один раз!)
4. Поклади мінімум **$5** на рахунок (Settings → Billing)

**Скільки коштують $5?** Більше ніж здається:

```python
# experiments/00_cost_calculator.py — запусти щоб відчути масштаб
# GPT-4o-mini: $0.15 за 1M input токенів, $0.60 за 1M output токенів

questions     = 20           # питань в eval set
avg_input_tk  = 300          # system prompt + питання
avg_output_tk = 200          # відповідь моделі

cost_per_q = (avg_input_tk * 0.15 + avg_output_tk * 0.60) / 1_000_000
total_cost = questions * cost_per_q

print(f"Одне питання:          ${cost_per_q:.6f}")
print(f"Весь eval set (20 пит): ${total_cost:.4f}")
print(f"На $5 вистачить на:    {int(5 / cost_per_q):,} питань")
```

Вивід:
```
Одне питання:          $0.000165
Весь eval set (20 пит): $0.0033
На $5 вистачить на:    30,303 питань
```

GPT-4o-mini надзвичайно дешевий. GPT-4o (~$2.50/1M input) у 17x дорожчий — тримай його для фінальної оцінки.

## 💻 Практика: запуск `00_setup_check.py`

```python
# experiments/00_setup_check.py
import os
import sys
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

if not os.getenv("OPENAI_API_KEY"):
    print("⛔ OPENAI_API_KEY не знайдено! Перевір .env файл.")
    sys.exit(1)

print("=== ПЕРЕВІРКА СЕРЕДОВИЩА ===\n")

# 1. Локальна модель
print("1. Ollama (локально)...")
try:
    import ollama
    resp = ollama.chat(
        model='qwen2.5:7b',
        messages=[{'role': 'user', 'content': 'Скажи "OK" якщо працюєш.'}]
    )
    print(f"   ✅ Qwen-7B: {resp['message']['content'].strip()}\n")
except Exception as e:
    print(f"   ❌ Ollama: {e}")
    print("   → Переконайся що 'ollama serve' запущено\n")

# 2. OpenAI API
print("2. OpenAI API...")
client = OpenAI()
resp = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Скажи 'OK' якщо працюєш."}]
)
print(f"   ✅ GPT-4o-mini: {resp.choices[0].message.content.strip()}\n")
print("✅ Все готово до бою!")
```

**Запуск:**
```bash
python experiments/00_setup_check.py
```

**Очікуваний результат:**
```
=== ПЕРЕВІРКА СЕРЕДОВИЩА ===

1. Ollama (локально)...
   ✅ Qwen-7B: OK

2. OpenAI API...
   ✅ GPT-4o-mini: OK!

✅ Все готово до бою!
```

## 📝 Завдання: вибір ніші (1 година)

Більшість студентів застрягають тут — хочуть "ідеальну нішу" або беруть занадто широко. Є простий фільтр:

### Тест ніші — відповідь "ТАК" на всі три:

```
1. ЧИ ІСНУЄ ПРОБЛЕМА?
   Знайди 3 пости на Reddit, форумах, або групах де люди питають про це.
   Немає постів → немає проблеми → немає ніші.

2. ЧИ ТИ МОЖЕШ ОЦІНИТИ ЯКІСТЬ?
   Ти сам (або простий скрипт) розумієш що таке "правильна відповідь"?
   Якщо ні → ти не зможеш виміряти покращення → курс не дасть тобі результату.

3. ЧИ ХТОСЬ ПЛАТИТЬ?
   Є фріланс-запити на Upwork/Freelancehunt, компанії що шукають таке рішення,
   або продукти що вже монетизують цю задачу?
```

**Хороші ніші** (є проблема + перевірювана + монетизована):
- Юридичні консультації по КЗпП → відповіді з номерами статей
- Медичні нотатки → структурований SOAP-формат
- HR-скринінг резюме → відповідність вимогам вакансії
- Підтримка клієнтів → категоризація і перший відгук

**Погані ніші** (занадто широко або неперевірювано):
- "Загальні знання" → немає ground truth
- "Творчий асистент" → немає об'єктивної метрики
- "Всі теми одразу" → ніша = спеціаліст, не generalist

Відкрий будь-який текстовий редактор і запиши:

```
1. ЗАДАЧА: "[вхідний текст] → [вихідний текст]"
   Приклад: "Юридична ситуація → застосовні статті і ризики"
   Приклад: "Технічне завдання → оцінка часу розробки"
   Приклад: "Медичні симптоми → можливі діагнози з вірогідністю"
   
   Твоя ніша: _______________________________________________

2. ПЕРЕВІРКА: "Як я зможу сказати 'правильно/неправильно' БЕЗ людини-експерта?"
   (якщо не можеш відповісти — ніша занадто розмита)
   
   Моя перевірка: ___________________________________________

3. КЛІЄНТ: "Хто платить і скільки разів на місяць потрібна ця задача?"
   
   Мій клієнт: _____________________________________________
```

> 💡 **Якщо не можеш вибрати** — використовуй юридичну нішу з прикладів курсу.  
> Можна змінити нішу після Тижня 1 коли побачиш як все працює.

## 🔥 Якщо не працює

### `OPENAI_API_KEY не знайдено`
- Перевір що файл `.env` знаходиться в **тій самій папці** де запускаєш скрипт
- Перевір що немає пробілів навколо `=`: правильно `KEY=sk-...`, неправильно `KEY = sk-...`

### `ollama: command not found`
- Ollama не встановлено або не перезапустив термінал після встановлення
- Windows: спробуй `winget install Ollama.Ollama` і відкрий **новий** термінал

### `connection refused` для Ollama
- Ollama не запущена. Запусти: `ollama serve` (в окремому терміналі)
- Або: перезапусти Ollama з іконки в system tray

### `AuthenticationError: Incorrect API key`
- Ключ скопійований неправильно (з пробілами чи без `sk-`)
- Ключ не має коштів: зайди на platform.openai.com → Billing

### `ModuleNotFoundError`
```bash
pip install openai anthropic ollama python-dotenv scipy
```
