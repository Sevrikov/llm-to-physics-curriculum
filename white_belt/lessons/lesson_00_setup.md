## 📖 Теорія (10 хвилин)

### Що таке LLM і навіщо нам API?

LLM (Large Language Model) — модель що передбачає наступний токен за попередніми. Вона не "думає" і не "розуміє" — вона статистично продовжує текст.

Є два способи використовувати LLM:
1. **Через API** (OpenAI, Anthropic) — платно, модель на чужих серверах
2. **Локально через Ollama** — безкоштовно, модель на твоєму комп'ютері

На цьому курсі ти будеш використовувати обидва. Ollama — для більшості розробки (безкоштовно), OpenAI API — для оцінки і складних задач.

### Чому важливо вибрати нішу ЗАРАЗ?

Без конкретної ніші ти будеш вчитись на абстрактних прикладах і не побачиш реального gap між "просто GPT-4o" і "GPT-4o з твоїм промптом". Ніша = мотивація + вимірювана ціль.

## 💻 Практика: запуск `00_setup_check.py`

```python
# experiments/00_setup_check.py
import os
import sys
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

if not os.getenv("OPENAI_API_KEY"):
    print("⛔ OPENAI_API_KEY не знайдено! Перевір .env файл.")
    sys.exit(1)

print("=== ПЕРЕВІРКА СЕРЕДОВИЩА ===\n")

# 1. Локальна модель
print("1. Ollama (локально)...")
try:
    import ollama
    resp = ollama.chat(
        model='qwen2.5:7b',
        messages=[{'role': 'user', 'content': 'Скажи "OK" якщо працюєш.'}]
    )
    print(f"   ✅ Qwen-7B: {resp['message']['content'].strip()}\n")
except Exception as e:
    print(f"   ❌ Ollama: {e}")
    print("   → Переконайся що 'ollama serve' запущено\n")

# 2. OpenAI API
print("2. OpenAI API...")
client = OpenAI()
resp = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Скажи 'OK' якщо працюєш."}]
)
print(f"   ✅ GPT-4o-mini: {resp.choices[0].message.content.strip()}\n")
print("✅ Все готово до бою!")
```

**Запуск:**
```bash
python experiments/00_setup_check.py
```

**Очікуваний результат:**
```
=== ПЕРЕВІРКА СЕРЕДОВИЩА ===

1. Ollama (локально)...
   ✅ Qwen-7B: OK

2. OpenAI API...
   ✅ GPT-4o-mini: OK!

✅ Все готово до бою!
```

## 🔥 Якщо не працює

### `OPENAI_API_KEY не знайдено`
- Перевір що файл `.env` знаходиться в **тій самій папці** де запускаєш скрипт
- Перевір що немає пробілів навколо `=`: правильно `KEY=sk-...`, неправильно `KEY = sk-...`

### `ollama: command not found`
- Ollama не встановлено або не перезапустив термінал після встановлення
- Windows: спробуй `winget install Ollama.Ollama` і відкрий **новий** термінал

### `connection refused` для Ollama
- Ollama не запущена. Запусти: `ollama serve` (в окремому терміналі)
- Або: перезапусти Ollama з іконки в system tray

### `AuthenticationError: Incorrect API key`
- Ключ скопійований неправильно (з пробілами чи без `sk-`)
- Ключ не має коштів: зайди на platform.openai.com → Billing

### `ModuleNotFoundError`
```bash
pip install openai anthropic ollama python-dotenv
```
