## 📖 Теорія (15 хвилин)

### Навіщо взагалі міряти baseline?

Уяви що хочеш схуднути. Якщо не зважився до — як дізнаєшся чи прогрес є?

Те ж саме з LLM. Більшість людей одразу "вдосконалюють" промпт не знаючи від чого стартують. В результаті:
- Змінили промпт → відповіді стали "краще на відчуття" → але метрика не змінилась
- Або навпаки: змінили → стало гірше → але не помітили

**Baseline = нульова точка.** Все що ти робиш далі — порівнюється з нею.

### Що таке "zero-shot"?

Zero-shot = модель відповідає **без жодного системного промпту і без прикладів**.

```python
# Zero-shot: тільки питання
messages=[{"role": "user", "content": "Ваше питання тут"}]

# Few-shot: питання + приклади
messages=[
    {"role": "user",      "content": "Приклад питання"},
    {"role": "assistant", "content": "Приклад відповіді"},
    {"role": "user",      "content": "Реальне питання"},
]
```

На цьому уроці — **тільки zero-shot**. Ніяких промптів. Ми міряємо "голу" модель.

### Чому важливо порівняти кілька моделей?

- **Qwen-7B (локально)**: безкоштовно, потужна, але може не знати регіональне законодавство
- **GPT-4o**: найсильніша, дорога, може галюцинувати факти
- **GPT-4o-mini**: дешева, швидка, якість трохи нижче GPT-4o

Твоя система в кінці курсу має **перемогти GPT-4o zero-shot** у твоїй ніші. Зараз ти побачиш наскільки складне це завдання.

## 💻 Практика: запуск `01_first_fight.py`

### Крок 1: Підготуй 20 питань ніші

**Важливо:** Це реальні питання що ставлять люди, НЕ учбові. Бери з:
- Форумів (Reddit, Stack Overflow, тематичні форуми)
- FAQ конкурентів
- Питань що тобі самому задавали по темі
- "Люди також шукають" в Google

```python
# experiments/01_first_fight.py
"""
ПЕРШИЙ БІЙ: порівнюємо 3 моделі на 20 питаннях твоєї ніші.
Це baseline — точка відліку для всього курсу.
"""
import json
import ollama
from openai import OpenAI
from pathlib import Path

# ================================================================
# НАЛАШТУЙ ЦЕ ПІД СВОЮ НІШУ — замни на свої питання!
NICHE = "юридичні консультації по трудовому праву України"

QUESTIONS = [
    "Роботодавець затримав зарплату на 10 днів. Що я можу зробити?",
    "Мене звільнили під час випробувального терміну. Чи законно?",
    "Як правильно оформити відпустку за власний рахунок?",
    "Роботодавець змушує підписати нову угоду з гіршими умовами. Можна відмовитись?",
    "Чи можна звільнити вагітну жінку?",
    "Скільки днів відпустки я маю право на рік?",
    "Роботодавець не виплатив компенсацію при звільненні. Куди звернутись?",
    "Чи законна робота без трудового договору?",
    "Які штрафи загрожують роботодавцю за затримку зарплати?",
    "Як розраховується вихідна допомога при скороченні?",
    "Можна відмовитись від понаднормової роботи?",
    "Чи може роботодавець зменшити зарплату в односторонньому порядку?",
    "Що робити якщо роботодавець не підписує заяву на звільнення?",
    "Скільки лікарняних днів оплачується?",
    "Чи є різниця між звільненням і скороченням штату?",
    "Що таке матеріальна відповідальність працівника?",
    "Як захиститись від незаконного звільнення?",
    "Чи може роботодавець вимагати відпрацювання 2 тижні при звільненні?",
    "Що таке випробувальний термін і які його обмеження?",
    "Куди скаржитись на роботодавця?",
]
# ================================================================

client = OpenAI()

print(f"🥊 ПЕРШИЙ БІЙ: {NICHE}")
print(f"📋 Питань: {len(QUESTIONS)}\n")
print("Це займе 5-10 хвилин...\n")

results = []

for i, question in enumerate(QUESTIONS):
    print(f"[{i+1:2d}/{len(QUESTIONS)}] {question[:55]}...", end=" ", flush=True)
    
    row = {"question": question, "answers": {}}
    
    # Суперник 1: Qwen-7B без промпту (локально, безкоштовно)
    resp = ollama.chat(
        model='qwen2.5:7b',
        messages=[{'role': 'user', 'content': question}]
    )
    row["answers"]["qwen7b_zero"] = resp['message']['content']
    
    # Суперник 2: GPT-4o без промпту
    resp = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": question}]
    )
    row["answers"]["gpt4o_zero"] = resp.choices[0].message.content
    
    # Суперник 3: GPT-4o-mini без промпту (дешевший)
    resp = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": question}]
    )
    row["answers"]["gpt4o_mini_zero"] = resp.choices[0].message.content
    
    results.append(row)
    print("✅")

Path("data").mkdir(exist_ok=True)
with open("data/first_fight_results.jsonl", "w", encoding="utf-8") as f:
    for row in results:
        f.write(json.dumps(row, ensure_ascii=False) + "\n")

print(f"\n✅ Збережено: data/first_fight_results.jsonl")
print(f"💰 Приблизна вартість: ~${len(QUESTIONS) * 0.002:.2f}")
print("\nНаступний крок: аналіз результатів (урок нижче)")
```

### Типові патерни для юридичної ніші (приклад)

| Патерн | Симптом | Техніка-виправлення |
|--------|---------|---------------------|
| Неправильна юрисдикція | Qwen пише про Росію, не Україну | Системний промпт з явним "тільки Україна" |
| Відсутність конкретних норм | "Зверніться до юриста" без статей | Few-shot з прикладами де є статті |
| Занадто загальні поради | "Можна подати заяву" — куди? як? | CoT з кроками "розпиши дії по порядку" |
| Відповіді не по темі | Починає розповідати загальну теорію | OOD guard у системному промпті |

## 🔥 Якщо не працює

### `RateLimitError` від OpenAI
- Забагато запитів підряд. Додай `time.sleep(1)` між питаннями:
```python
import time
# після кожного row.append(row):
time.sleep(1)
```

### Ollama дуже повільно (>2 хв на відповідь)
- Це нормально на CPU для 7B моделі
- Можна замінити на `qwen2.5:1.5b` для тестування, але якість буде нижче

### Деякі відповіді порожні або `None`
- Модель повернула порожню відповідь (буває рідко)
- Додай перевірку: `row["answers"]["qwen7b_zero"] = resp['message']['content'] or "EMPTY_RESPONSE"`

### `JSONDecodeError` при читанні файлу
- Файл пошкоджений (скрипт впав посередині)
- Видали файл і запусти знову: `del data/first_fight_results.jsonl`
