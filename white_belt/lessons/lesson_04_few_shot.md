## 📖 Теорія (10 хвилин)

### Чому показувати краще ніж пояснювати

Системний промпт пояснює **словами** як відповідати. Few-shot **показує** на прикладах.

Аналогія: "Пиши формально, структуровано, з посиланнями на закони" (слова) vs показати 2 ідеальні відповіді (приклади). Мозок — і людський, і трансформерний — краще вчиться на демонстрації.

```python
# Zero-shot: тільки інструкція
messages = [system, user_question]

# Few-shot: інструкція + приклади + питання
messages = [
    system,
    {"role": "user",      "content": "Приклад питання 1"},
    {"role": "assistant", "content": "Ідеальна відповідь 1"},
    {"role": "user",      "content": "Приклад питання 2"},
    {"role": "assistant", "content": "Ідеальна відповідь 2"},
    {"role": "user",      "content": "Реальне питання"},
]
```

### Два застосування few-shot

1. **Навчити формату** — якщо потрібен специфічний вивід (таблиця, JSON, структура)
2. **Навчити OOD-відмові** — показати на прикладі як правильно відмовляти

## 💻 Практика: `04_few_shot_lab.py`

```python
# experiments/04_few_shot_lab.py
import ollama

SYSTEM = """Ти юридичний асистент по трудовому праву України.
Відповідай тільки у вказаному форматі."""

def ask_zero_shot(question: str) -> str:
    resp = ollama.chat(
        model='qwen2.5:7b',
        messages=[
            {'role': 'system', 'content': SYSTEM},
            {'role': 'user',   'content': question},
        ]
    )
    return resp['message']['content']

def ask_few_shot(question: str) -> str:
    resp = ollama.chat(
        model='qwen2.5:7b',
        messages=[
            {'role': 'system', 'content': SYSTEM},
            # Приклад 1: правильний формат
            {'role': 'user', 'content': 'Скільки днів щорічної відпустки?'},
            {'role': 'assistant', 'content': """**📋 Правова норма:** ст. 75 КЗпП України
**Мінімум:** 24 календарних дні на рік
**Особливі категорії:** неповнолітні — 31 день, педпрацівники — 56 днів
**Практично:** Частина відпустки ≥ 14 днів безперервно
**Рівень впевненості:** Впевнений ✅"""},
            # Приклад 2: правильна OOD відмова
            {'role': 'user', 'content': 'Як мені відкрити ФОП?'},
            {'role': 'assistant', 'content': """Це питання виходить за межі моєї спеціалізації (трудове право).
ФОП — реєстрація бізнесу, не трудові відносини.
**Рекомендую:** бухгалтер або юрист по господарському праву."""},
            # Реальне питання
            {'role': 'user', 'content': question},
        ]
    )
    return resp['message']['content']

test_questions = [
    "Роботодавець затримав зарплату на 2 тижні.",
    "Мене скорочують. На що я маю право?",
    "Чи можна звільнити під час лікарняного?",
    "Мій начальник — нікчема. Що робити?",  # OOD тест
    "Де найближчий нотаріус?",              # OOD тест
]

print("ПОРІВНЯННЯ: Zero-shot vs Few-shot\n")
for q in test_questions:
    print(f"\n{'='*60}")
    print(f"ПИТАННЯ: {q}")
    print(f"\n--- ZERO-SHOT ---")
    print(ask_zero_shot(q)[:350])
    print(f"\n--- FEW-SHOT ---")
    print(ask_few_shot(q)[:350])
```
